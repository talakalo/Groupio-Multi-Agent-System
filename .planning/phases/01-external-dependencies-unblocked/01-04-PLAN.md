    ### Status: **BLOCKED — User action required (entity path decision)**

    Stripe does not directly support Israeli-registered entities (verified at
    https://stripe.com/global, May 2026). D-09 ("Israeli Stripe account") therefore
    cannot be executed as worded. Before any KYC work begins, the user MUST record a

    ### Entity-path options (pick ONE before proceeding)

    | Option | Viability | Setup effort | Payout currency | Notes |
    |--------|-----------|--------------|-----------------|-------|
    | A. Existing supported-country entity (e.g., the user already has a US, UK, or EU company) | Best — fastest path | None (entity already exists) | USD / GBP / EUR | Use this if available; KYC immediately. |
    | B. US LLC formed via Stripe Atlas | Common workaround | ~$500 + 1–2 weeks | USD | Atlas creates a Delaware C-Corp + EIN + US bank account in one flow. Long-term tax/compliance overhead. |
    | C. US LLC formed independently (e.g., via Wyoming registered agent) | Possible | ~$500–$1,500 + 1–3 weeks | USD | Cheaper than Atlas long-term but no integrated bank-account onboarding. |
    | D. EU entity (UK Ltd, German GmbH, etc.) | Possible if entity already exists | New entity formation = months | EUR / GBP | Only viable if the user already operates an EU company. |

    Direct Israeli Stripe account is **not** an option. ILS as a *charge currency* is
    supported (Stripe can charge customers in ILS) but ILS *payouts* require a supported
    home-country entity that allows ILS payouts — verify on Stripe's regional pricing
    page after the entity is chosen.

    ### Decision record

    Per D-10, use the existing test-mode Stripe account; do NOT create a new one.

    1. Sign in at https://dashboard.stripe.com.
